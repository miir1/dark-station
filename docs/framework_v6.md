## 1. 세계관 — 규칙이 되는 진실

world.md 그대로. 게임 규칙과 닿는 것만:

| 진실 | 규칙 |
|---|---|
| 안개 = 세엘「세는 자」의 시선. 하늘이 보이는 데까지만 | 출구 계단이 막혀 있다. 지하가 집이다 |
| 보고 세고, 이름을 불러 대답하면 센다. 안 불린 채 들어가면 재 | 빛·소리 = 시선. 위에서 부르면 대답하지 마라 |
| 지하는 메아리로 셈이 어긋난다. **둘이 서면 흐려진다** | 경계 둘 = 시선 −. 세는 아이 장면의 해법 |
| 밤마다 역에서 새어 나간 빛·소리만큼 안개가 계단을 한 칸 내려온다 | 화로의 불 크기 = 시선 +. 불은 양날 |
| 지하 밑의 것들: 옛 물길의 숨(네레흐), 굶주림(구르마흐) | 침수·식량은 수치가 아니라 깨우는 것 |
| 방송 = 차량기지 직원들의 진짜 약속. D7부터 테르미아가 잇는다 | 열차는 열흘 뒤 정오. 운임은 빵·물·**소리 내어 한 약속** |
| **당신은 이 열차의 기관사였다** | 수첩이 당신 손에 있는 이유. 운전실의 구두 한 짝. D10 "다시 모시겠습니까" |
| **것들은 당신을 세지 않는다** (이유는 1막에서 말하지 않는다) | 당신은 전투·셈에서 다치지 않는다. 세는 아이가 당신 차례에 "…넷?" 하고 멈칫한다 — world 떡밥 ③의 기계적 단서 |
| 불을 지키면 히스카, 이름을 부르면 호 | 생존 행동이 곧 신에게 하는 말 |

낱말 셋을 가른다: **불** = 화로(땔감, 빛, 시선) / **전기** = 발전기(기철, 물 긷기·진료소) / 등불은 없다. 어두운 밤 = **화로가 꺼진 밤**. 발전기는 빛이 아니다.

막 전체(1막 을지로입구 지하 → 2막 고가 구간 역 → 3막 차량기지)는 v6 초안 1-2 그대로. 2막은 "틀은 같되 낮·밤 자리만 바뀐다" 한 줄만 적어 둔다.

## 2. 게임 틀

### 2-1. 하루 5단계

| 단계 | 화면 | 하는 것 | 거는 것 | 시간 |
|---|---|---|---|---|
| ① 아침 카드 | 화로 앞, 카드 1장 | 선택지 2개. 양쪽 값이 **다른 자원**으로 보인다 | 자원 ↔ 시선, 오늘 ↔ 내일 | 20초 |
| ② 자리 | **수첩 페이지** (걷기 없음) | 세 사람(서하·은지·동하)을 **오늘 비울 자리 하나**를 정하는 식으로 세운다. 고정 셋은 기본값 | 몸(감염)·마음 | 20초 |
| ③ 원정 (짝수 날만) | 손 지도 2층 + 장면·카드 | 둘 + **당신**. 어디로, 둘 중 누구. 사건 2~3장, 랜드마크 1 | 몸, 보급, 소원 물건 | 3~5분 |
| ④ 저녁 곁에 | 역 지도 — **그 사람에게 걸어간다** | 손님(약속)이 있으면 손님 먼저, 그 뒤에도 곁에 1칸 | 다른 사람의 소원은 하루 늦는다 | 40초 |
| ⑤ 밤 | 보고서(달라진 것만) + 사건 1장 | 즉답 | — | 40초 |

걷기는 ④와 조사(물건·사람 말 걸기)에만. 지도를 누르면 걸어간다(탭 걷기). ★가 있는 밤(D3·D5·D7·D9)은 **무작위 카드와 강림이 오지 않는다.**

### 2-2. 기본값이 정해진 셋 + 움직이는 셋

| 사람 | 기본 자리 | 반쪽 일(자동) | 비우면 |
|---|---|---|---|
| 순례 | 화로지기 | 역 안 수색 +1 (땔감 또는 식량) | 불이 한 단 작아진다 |
| 마리 | 치료 | 환자 없으면 물 긷기 2 | 치료 없음 |
| 기철 | 발전기 | 배수 +1 | 전기가 안 켜진다 — 물 긷기 막힘, 발전기 카드가 사라진다 |
| 서하·은지·동하 | 플레이어 | — | 원정에 둘을 쓰면 하나 남는다 |

기본값은 **바꿀 수 있되 값이 든다**(순례를 떼면 불 한 단, 기철을 떼면 전기 0). 엔진의 6명 배치 구조는 그대로 두고 '기본값 + 값'만 얹는다. 붕괴·중상이면 자리가 비고 반쪽 일도 멈춘다 → 플레이어가 대신 세운다. 고정 셋에게 **하루 한 번 말 걸기**(자리 옆 한 줄, 날마다 바뀜). 비극 전날엔 그 사람 말이 끊긴다.

### 2-3. 자리 6 (열리는 날에만 보인다)
수색(D1) · 물 긷기(D1) · 휴식(D1) · 경계(D3 밤 뒤, 순례: "경계는 둘이 서야 돼") · 공사(D4) · 배수(D5). 설명은 사람 입으로.

## 3. 생존

### 3-1. 압력 6 — 신 하나, 흔적 하나

| 압력 | 수치(내부) | 흔적(화면) | 모자라면 | 신 |
|---|---|---|---|---|
| 배고픔·목마름 | 식량·물 0~16 | 숫자 + 창고 상자 | 스트레스 +8/+10, 이틀 굶으면 부상 | 구르마흐 |
| 불 | 땔감 0~12 | 숫자 + 화로 불 3단 | 꺼진 밤: 어둠 사건, 스트레스 +4, 쥐가 창고를 턴다(식량 −2), 히스카 − | 히스카 |
| 물 | 침수 0~8 | 선로→승강장 물 | 5: 발전기 잠김, 8: 창고 침수 | 네레흐 |
| 빛·소리 | 시선 0~8 | 분필 벽, 계단 안개 칸 | 6: 순찰대·나방·징조 | 세엘 |
| 마음 | 스트레스 0~100 | 초상 3단, 머리 위 … | 80: 붕괴 확률, 100: 붕괴/각성 | (호가 붙잡는다) |
| 몸 | 부상 0~3, 상처, 피로 0~2 | 붕대, 저는 걸음, 앉음 | 경상으로 일하면 30% 곪음, 위독 하루 뒤 사망 | — |

**시선 수지(하루)**: 화로 불 크기 작음 0 / 보통 +1 / 큼 +1, 발전기 +1, 전투·파이프 소리 +1, 경계 둘 −2, 순찰대에 식량 −3. 세 사람 배치면 경계가 비는 날이 많다 → D6 전후 6에 닿는 것이 **의도**다(순찰대 D8).

### 3-2. 땔감 — 역을 태워서 산다
- 화로는 밤마다 땔감 1. 화덕(부품 4)은 땔감 1로 이틀. 없으면 꺼진 밤.
- **역에서 나오는 땔감 상한 5**(의자 둘 1·1, 게시판 1, 역무실 서류 1, 전동차 좌석 1). 수색은 식량 3 + 땔감 1을 **같이** 가져온다(토글 아님). 원정 사건에서 땔감 1~2.
- 시작 6. 열흘 10 필요 → 역 5 + 수색 열흘 ≈ 3~5 + 원정. **최소 두 밤은 "뜯거나, 어둡거나"** 가 되도록 봇으로 맞춘다(합격선 §8).
- 뜯을 것마다 **임자와 한 줄**, 뜯으면 그 물건의 저녁 대화 하나가 사라진다:

| 뜯는 것 | 임자 | 사라지는 것 | 한 줄 |
|---|---|---|---|
| 의자 ×2 | 잠자리 | 휴식 회복 −16 → −12 (영구, 하나당 −2) | "오늘 밤부터 둘이 바닥에서 잔다" |
| 게시판 | 순례 | 순례의 '못 받은 전화' 대화 | "거기 아들 번호를 적어 뒀는데." |
| 역무실 서류 | 기철 | 그날 근무자 명단 (기철 2단계 단서) | 기철이 명단을 불에서 꺼내려다 손을 덴다 |
| 전동차 좌석 | **당신** | — | "자기 열차를 뜯는 기관사" — 결말 당신 줄에 한 마디 (C의 공짜 단서) |
| 은지의 간판 | 은지 (소원 3단계) | 땔감 3, 은지가 어머니 이름을 소리 내어 부른다(호 +2) | 위로 결말 |

'영원의 불씨'(히스카 강림)는 땔감 체계 안: **땔감 없이 타는 불**(소모 0), 지킴이는 묶인다. 장례의 값은 땔감이 아니라 **이름 부르기**(호 +1, 시선 +1).

### 3-3. 가혹함을 보이게

| 바꿈 | 이유 |
|---|---|
| 경상 회복 하루 → **이틀**. 원정 귀환에도 감염 굴림(경상인 채 원정 → 30%) | 경상인 채 하루 더 쓰는 유혹. 원정이 더 안전한 구멍을 막는다 |
| 귀환 스트레스 +12 → +8 + **피로 1**. 피로 2면 원정 불가. 회복은 **원정 안 간 날** −1(배치와 무관) | 둘 중 누구를 보낼지가 결정이 된다. 짝수 날 원정이면 피로로 막히지 않는다 |
| 상처 굴림: 중상 + **붕괴 때도**(도주→다리, 폭력→손) | 상처 보유자 판당 ≥1 |
| 밤 보고서 맨 위 **잃은 것**: 지도에서 사라지는 물건 + 사람 한마디. 열흘 중 **두 밤**은 아무것도 안 잃고 "줄어든 게 없다. 그게 더 이상했다." | 영수증이 아니라 장면. 리듬을 깬다 |
| 당신은 다치지 않는다 — 대신 **원정 둘이 모두 쓰러지면 당신 혼자 돌아온다**(둘은 다음 날 아침 기어 돌아온다, 중상) | 안전한 몸이 남의 일이 되지 않게 |

**잃은 것 후보 10**: 물통 하나 샘(물 −1) / 붕대 한 장(약품은 그대로, 다음 치료가 하루 늦음) / 담요 찢김(누구 스트레스 +3) / 땔감 한 개 젖음(−1) / 게시판 종이 한 장 날아감 / 건빵 봉지 쥐(식량 −1) / 램프 유리 깨짐(시선 −1, 어두움) / 누군가의 밤잠(휴식 −8) / 분필 한 자루 / 당신의 손전등 깜빡임(다음 원정 첫 사건 관찰 −1). 조건·글 한 줄은 데이터에서.

### 3-4. 열흘 예산 (엔진 수로, [제안] — 봇으로 재서 고친다)

| 자원 | 필요 | 공급 | 적자가 나는 날 |
|---|---|---|---|
| 식량 | 역 소비 4/일 ×10 = 40 + 원정 4회 × 4~6 = 20 + **운임 1/명 = 7** → **67** | 수색 풀 52(서하 5·은지 4·동하 3 + 순례 +1) + 원정 2~3/회 + 약국·노점 | D6~8 |
| 물 | 40 + 20 + 7 = **67** | 물 긷기 4~5/일(전기 필요) + 마리 2 + 원정 | D5 범람 뒤 (발전기 잠김) |
| 땔감 | 10 (+횃불 1~2) | 시작 6 + 역 5 + 수색 3~5 + 원정 | D4~6 |
| 부품 | 통로 3 + **화덕 4 또는 진료소 4**(같은 4를 다툰다) + 들것(중상자 수 × 2) + 쇠줄 1 → 8~12 | 원정 2~3/회, 시작 4 | D4 (열쇠 값) |
| 약품 | 치료 1/회 | 원정·약국·협정 | 부상 난 날 |

**운임은 1/명**(초안 2에서 내림). 16 상한에서 14를 운임에 쓰면 열흘이 운임 저금이 되기 때문. 그리고 **소리 내어 한 약속 하나가 한 사람의 운임을 대신한다**(테르미아의 규칙 — 손등 구멍 하나 = 한 자리). 세 사람 배치로 물·식량이 도는지는 승인 조건 — **stay 봇 D10 식량·물 ≥ 12**.

## 4. 전투

### 4-1. 자리
보스 둘(뼈 줍는 이·익사자 무리)만 부위 전투, 세는 아이는 **셈 장면**(전투 화면 아님). 잡것은 카드 선택지. 모든 랜드마크에 '싸우지 않는 길'이 있지만 **싸워야 전부를 얻는다**(통행료는 안전을 살 뿐).

### 4-2. 규칙
| 요소 | 규칙 |
|---|---|
| 편성 | 둘. 당신은 지시만 — "것들은 당신을 세지 않는다" |
| 예고 | 적이 다음에 노릴 **사람**만 미리 보인다(부위는 비밀) |
| 막기 | 예고된 사람이 막으면 피해 **−1**(0 아님). **막은 턴엔 보스 고유 규칙이 한 칸 진행**(물이 찬다 / 뼈를 줍는다) — 막을지 때릴지가 갈림 |
| 보스 공격 | 라운드당 2회(예고 1 + 무작위 1) |
| 도구 | 쇠파이프 +1, 밧줄(다리 1턴 묶음), 횃불(출발 때 "횃불 하나 챙긴다(땔감 1)", 적이 1턴 물러남) |
| 도망 | 다리를 부수면 확정. 아니면 관찰 판정 |
| 상처 | 부러진 부위 → 부상 + 영구 상처 굴림 |
| 소리 | 파이프로 철문·횃불 → 시선 +1 |
| 구현 | 전투 상태 기계를 **엔진으로**(rand(s), battleStart/battleAct dispatch), v3는 그리기만 → 봇이 보스까지 잰다 |

### 4-3. 랜드마크 셋

| 랜드마크 | 어디 | 고유 규칙 | 싸우지 않는 길 (하나만 얻는다) | 싸워 이기면 (전부) |
|---|---|---|---|---|
| 뼈 줍는 이 | 지하상가 2층 (D4~) | 막은 턴마다 부서진 부위를 주워 간다(상처 확정) | 손가락 하나(상처) → 은지 간판 **또는** 약품 2 | 간판 + 약품 2 + 순례 전화 카드가 없었다면 여기서도 |
| 익사자 무리 | 배수로 2층 저수조 (D6~, 범람 뒤 열림) | 전투 안 수위 0→6. 막은 턴 +1. 4: 다리 공격 불가, 6: 강제 도망 | 물 ≥4 전부 붓는다 → 기철 명단 | 명단 + **밸브 열쇠**(역 침수 −2 영구) + 부품 2 |
| 세는 아이 | 안개 2층 (D6~) | **셈 장면** 3턴. 아이가 센 수가 화면에 보인다(우리 둘 = 2). 턴마다 '숨 죽인다(그대로) / 이름을 부른다(+1) / 한 사람을 뒤돌려 보낸다(−1)'. 3턴 뒤 수가 **2가 아니면 차이만큼 세어진다**(실종). 판정 없음. 당신 차례에 아이가 "…넷?" 하고 다시 센다 | 둘 다 뒤돌려 보낸다(0) — 아이가 "영"이라 말하고 사라진다. 배터리 없음 | 수를 2로 맞추고 끝까지 → 서하 배터리 + 다음 날 계단의 재가 한 칸 **올라가** 있다 |

### 5-3. 수첩 — 판을 넘어
- 징조마다 뒷장에 신의 규칙 한 줄(최대 7, **신만**; 보스는 앞장의 그림 한 장).

### 5-4. 당신
수치 없음. **손등 구멍 = 소리 내어 한 약속의 수**(지킨 것·어긴 것 모두). 어긴 자리는 찢긴다. 구멍 하나 = 운임 한 자리. 검표(D9)에서 뚫리고, 결말 당신 줄에 "구멍 셋, 찢긴 것 하나".
