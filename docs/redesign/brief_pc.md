# 어두운 역 — 초고 공통 전제 (PC 웹게임 판, 2026-10-21)

이 전제는 docs/framework_v6.md(게임 틀 v6.1)와 docs/redesign/world.md(세계관) 위에 얹는다. 두 문서와 어긋나면 **이 문서가 이긴다.**

## 사용자 결정 (2026-10-21, 전부 채택)
1. **땔감**: 다섯 번째 자원. 화로가 밤마다 1을 먹고, 역을 뜯어서(임자 있는 물건) 얻는다. 역에서 나오는 땔감 상한 5.
2. **운임 1/명** + **소리 내어 한 약속 하나 = 한 사람 자리**(손등 구멍).
3. **수첩 이월**: 배운 신의 규칙은 다음 판에도 남지만 D7 방송 저녁까지 잠겨 있다가 "낯익은 글씨"로 펼쳐진다. 이득은 새 선택지가 아니라 힌트의 확신.

## 플랫폼 전환: 폰 세로 → PC 웹게임 (브라우저, 가로 화면)
지금까지 모든 설계는 폰 세로(390×844) 기준이었다. 이제 **PC 브라우저가 1순위**다. 폰은 가로로 돌리면 돌아가는 정도면 된다.

| 항목 | 정한 것 |
|---|---|
| 기준 해상도 | 1280×720 (16:9). 1920×1080에서는 정수 배율로 키운다 |
| 타일·배율 | 타일 32px, 720p에서 배율 2 → 지도 상자 960×640 = 한 화면 **15×10칸**(처음 적은 20×11은 지도가 1280 전체일 때의 수 — GDD 초고가 바로잡음). 1080p 배율 3 |
| 화면 구성 | 가운데 지도(960×640) + **오른쪽 패널**(320px: 날짜·열차까지·자원 셋·수첩 탭·명부 탭) + 아래 대화창(RPG Maker식, 지도 아래 1/3을 덮는 창, 초상 96 왼쪽) |
| 입력 | 키보드: 화살표/WASD 이동, Space/Enter 조사, Esc 메뉴, 1~4 선택지, Tab 수첩. 마우스: **클릭한 칸까지 걸어간다**, 물건·사람 클릭 = 조사, 선택지 클릭, **마우스를 올리면 설명**(판단 정보는 툴팁으로 친절하게) |
| 글자 | 720p에서 본문 16px, 대화 18px, 보조 14px. 창 크기에 비례 |
| 십자키·터치 패드 | 없앤다(폰 가로에서는 터치로 클릭 걷기만) |
| 저장 | 자동 저장 + **저장 코드 내보내기/불러오기**(텍스트) — PC 플레이어가 원한다 |
| 소리 | 지금 웹 오디오 그대로 + 설정에 음량 |
| 창 | 전체 화면 버튼(F). 브라우저 창이 작으면 배율 1로 떨어진다 |

왜: 사용자 요청 "게임을 컴퓨터 웹게임용으로 친화적으로". PC는 화면이 넓어 **지도와 패널과 대화창을 동시에** 둘 수 있고, 마우스 호버로 '판단 정보 친절하게'가 훨씬 쉽다. 폰 전용 제약(한 화면 12칸, 숫자 셋만, 아래 1/3 덮기)은 PC에서는 풀어도 된다 — 단 **숫자로 보이는 것은 여전히 식량·물·땔감 셋**(패널), 나머지는 흔적.

## 산출물 규칙
- 한국어. 사용자는 코드를 쓰지 않는다 — 쉬운 말.
- 자기 파일 하나만. 코드·그림·다른 문서는 건드리지 않는다.
- '초고'다: 완성도보다 **전부가 한 번 적혀 있는 것**이 중요하다. 빈 곳은 [비움]으로 표시하고 넘어간다.

## 초고 뒤 결정 (2026-10-21, 리드)
| 질문 | 결정 |
|---|---|
| 한 화면 칸 수 | **15×10** (패널은 불투명, 지도 상자 960×640). 역 28×16이 가로 2화면이라 스크롤 감은 그대로 |
| 초상 크기 | 도트 굵기 통일 — 대화창 초상 **192px**(96도트×2). 대화창 높이 240 |
| 결말 수첩 종이 그림 | 예외 **허용** (세계 안의 물건) |
| D7 "여기 있습니다" | **자리 +1은 뺀다.** 구멍(약속) 하나만 — "약속 하나 = 자리 하나" 규칙과 겹치지 않게 |
| 비극 수위 | 사용자 결정 그대로: 플레이어 선택으로만 **실제로 떠난다**(순례 올라감, 기철 재) |
| 기철 두 딸·동하 진짜 이름 | 사용자에게 묻는다 (아래) |
