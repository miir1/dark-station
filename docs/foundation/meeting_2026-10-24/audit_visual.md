**"움직이면" 잘리는 이유**: 서 있을 땐 대개 '아래 보기'(온전한 줄)인데, 움직이는 순간 왼·오·위 줄로 바뀌기 때문. 첫 장면(전동차)은 시작부터 오른쪽을 본다(game.js:48 `'right'`) → 첫 화면부터 잘린 머리.

**원인 줄(그림 도구)** — 원본 시트는 AI가 줄 간격을 고르게 안 그렸다(아래 줄일수록 그림이 위로 밀림). 도구는 고른 칸으로 자른다.
| 위치 | 하는 일 | 결과 |
|---|---|---|
| `tools/chunky.py:146` | 칸 = 원본을 3열×4행 **고른 격자**로 나눔 | 칸 선 위로 넘어간 머리는 '윗칸' 소속이 됨 |

## 2. U3 프레임 — 측정값
| 항목 | 측정 | 근거 |
|---|---|---|
| 화면 갱신 | `setInterval(frame, 1000/30)` = 30번/초, 모니터 박자(vsync)와 무관 | game.js:1002 |
| 디렉터 모니터 | 2560×1440 **143Hz**, 배율 100%(DPR 1) → 최대화 창 3배(1920×1080)·전체화면 4배 | Win32_VideoController, AppliedDPI=96 |
| 143Hz 위 30fps | 한 장면이 모니터 4장·5장씩 번갈아 보임(4.8) → 고르지 않은 덜컥임 | 계산 |
| 갱신 간격 흔들림 | 헤드리스 실측 17~48ms(평균 33) | walk_timing.json dt_ms_min/max |
| 한 번에 움직이는 거리 | 4.3px(논리) ≈ 화면 13px(3배) 씩 점프 | px_per_frame_hist(대부분 4.2~4.5) |
| **칸마다 멈춤** | 한 칸 도착 프레임과 다음 칸 시작 프레임이 **같은 자리** → 칸마다 1프레임(33ms) 정지. 6칸에 5번 | stall_frames_while_walking=5, first40: 343ms·370ms 둘 다 64px |
| 원인 줄 | 도착하면 `return` 하고 다음 칸은 다음 프레임에 t=0 으로 시작, 남은 시간(t>1 초과분)은 버림 | game.js:178-180, 204 |
| 실제 한 칸 시간 | 설계 230ms → 실측 **264ms**(15% 느림, 리듬 불규칙) | first40: 32→64→96→128px 가 343·607·870·1134ms |
| 걷기 그림 수 | 3장(왼발·섬·오른발), 4박자(왼-섬-오-섬)로 씀 — RPG 메이커 표준과 같음 | art.js:101-116 |
| 걷기 박자 | 칸마다 섬 ~3프레임 + 발 ~5프레임(t 0.15~0.85), 실측 순서 `MMLLLLLMMMMRRRRR…` | render.js:185, walk_seq |
| 달리기(Shift) | 한 칸 126ms = 3.8프레임 → 한 번에 8.4px 점프, 발 그림 2~3프레임 | game.js:178 `ms*0.55` |
| 걷기 그림끼리 차이 | 한 줄 안 3장이 픽셀 600~900개 다름(서로 따로 그린 그림) → 몸 폭이 16↔29px 로 출렁 | sprites.json diff_LM, x0~x1 |
| 방향 바꿀 때 키 변화 | 당신: 아래 보기 머리 꼭대기 0~2px, 오른쪽 5px(잘린 탓) → 돌면 키가 줄어 보임 | sprites.json walk.player |
| NPC | 걷지 않음, 숨쉬기·흔들림 없음(frame 0 고정) | game.js:114, render.js:176 |
| 불꽃 | 사각형 3장, 4틱마다(7.5장/초) | render.js:164-167 |
| 빛 떨림 | 8틱마다 3단계(3.75장/초) | render.js:171 |
| 대사 글자 | 18ms/글자(55자/초), 화면 갱신과 별개 → 끊김 없음 | engine.js:25, ui.js:48 |
| 그리기 비용 | 한 장 1.7ms(헤드리스·소프트웨어) → 60·144fps 여유 충분 | draw_ms_avg |

**고칠 길**: ① 화면 갱신을 `requestAnimationFrame`(모니터 박자)으로, 창이 숨으면 지금처럼 setInterval(캡처용) ② 칸 도착 프레임에서 남은 시간을 넘겨 **같은 프레임에 다음 칸 시작**(멈춤 0) ③ 걷기 그림은 시간(t) 대신 **걸은 거리**로 고름(16px마다 왼-섬-오-섬) ④ 그림 쪽은 걷기 4~6장으로(Codex 필요 — 9명 × 1회, 예산 판단) ⑤ NPC 숨쉬기 1px(그림 추가 없음).
