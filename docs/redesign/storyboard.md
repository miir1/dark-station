## 3. 막의 감정 곡선과 '달라졌다' 장치

| 막 | 감정 곡선 한 줄 | 막이 바뀔 때 플레이어가 느낄 것 |
|---|---|---|
| 프롤로그 | 혼자 → 무섭다 → 사람을 만나 잠깐 안도 → 계단을 보고 다시 무섭다 | 화면: 검정·빨강(비상등)만 → 마지막에 주황(화로). 소리: 울림 → 정적 → 사람 목소리 |
| 1막 D1~3 | 바쁘다. 규칙을 익히느라 두려움을 잊는다 → D3 밤에 '누가 우리를 센다'로 끝난다 | 1막 시작: 날짜 카드와 종 소리가 처음 생김. 1막 끝(F3): 수첩 뒷장이 처음 열리고 '시선' 칸이 생긴다 |
| 2막 D4~7 | 물이 차고 배가 고프다. 안개가 매일 한 칸 내려온다. 열차가 구조가 아닐지도 모른다 | 2막 시작: 막 제목 카드 "2막 · 물과 굶주림"(현행) + 화면 아래쪽 물빛 반사가 생김(→ art.md). 2막 끝(I4): 방송 목소리에서 숨소리가 사라진다 — P5·B4와 같은 스피커인데 다르다 |
| 3막 D8~10 | 사람(순찰대)이 가장 무섭다 → 검표에서 자기 행동을 읽힌다 → 누구를 태울지 | 3막 시작: 막 카드 "3막 · 검표" + 날짜 옆에 "열차까지 N일"이 **크게** 바뀜. 안개는 계단 아래 두 칸까지. 3막 끝: 열차 소리가 처음 들린다 |
| 결말 | 조용하다. 읽어 주는 것을 듣기만 한다 | 조작이 [누르기]만 남는다. 음악 없이 종과 정적 |

공통 장치(제안): 막이 바뀌는 밤마다 수첩 뒷장이 한 장 넘어가고, 안개가 계단에서 한 칸 내려온 그림이 배경에 반영된다(P4 → H1 → 3막). "달라졌다"는 느낌은 새 화면보다 **같은 장소의 작은 변화**로 준다(같은 스피커, 같은 계단, 같은 수첩).
