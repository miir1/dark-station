# 《어두운 역》 큰 틀 — Claude 설계 패널 최종안 (2026-10-15)
(4관점 독립 설계 → 통합 → 3관점 비판 → 최종. 원본: workflow wf_c1061e30-53a)


## 1. 한 줄 요약

《어두운 역》은 「명부(名簿)를 쓰고 지키는」 60일짜리 지하철 대피소 운영 + 지상 원정 로그라이크다.
■ 정체성: 일손 한 칸 = 사람 한 명 = 마음 한 칸 = 명부 한 줄.
■ 목표(상단 띠): 「명부에 쓴 이름을 한 사람이라도 더 살려 D60의 마지막 장을 읽는다.」 예) [Day 17 | 물때① D-3 | 명부 8명 · 지운 이름 1]
■ 구조: 하루 5단계 턴제(실시간 틱·불 지피기 폐기). 장부(청구서+3일 예보) 읽기 → 이름 있는 주민 배치 → 원정(2~3명, 구멍 메우기) → 저녁 화로 대화 → 밤 자동 정산. 달력에는 약탈·공물·유행과 안개 '물때'(문을 닫고 3·4·4일 버티기) 3회가 박혀 있고, D60 낮에 문을 열어 「최후의 밤」을 치른 뒤 명부를 낭독한다.
■ 사용자가 고른 3방향(일 단위 / 이름 있는 주민 / 멈춘 전동차 프롤로그)은 전부 유지. 초안의 '역장 교대'는 1.0에서 제외(M8 선택 확장).
■ 참고작에서 가져온 것
- A Dark Room: 희소성→위협→병목 이동, 재료를 먹는 변환(필터·버섯·조제), 가방 칸=원정 사거리, 창고 상한, 가격 상승(숙소 ×1.25), 건조한 로그 톤.
- 서울 2033(브리프 확인 범위만): 사건 카드, 선택 결과가 상처·스트레스·소지품으로 남아 이후에 영향, 능력·소지품에 따라 열리고 닫히는 선택지 → 선택지 조건 태그 [장비][시설][특성][상처][기술N][동행] + 결과를 개인 상태·소지품·세계 플래그 3곳에 저장.
- Darkest Dungeon: 마을↔원정 이중 루프, 가보→청사진(신조 T3 해금), 개별 인물·특성·영구 이별, 스트레스→고통/미덕(심장마비 즉사는 '이탈'로 대체), 랜턴 3단, 보급 선택, 술집/수도원→휴게 바/침묵실, 후퇴 판단, 신입 도착→밤의 쪽문. 일부러 안 가져옴: 턴제 전투·직업/스킬·골드·4인 파티.
■ 표기: [시뮬]=이미 측정(구 규칙 기준), [제안]=미측정 설계값, [재측정]=이번에 규칙을 바꿔서 다시 돌려야 하는 값. 초안의 '균형 봇 92%/81%'는 독립 재구현에서 재현되지 않아 폐기했다. 기준선은 측정치 상식적 봇(BAL) 도달 65~69%/양호 37~42%, 최적화 봇(OPT) 83~86%/64~70%이다(양호=생존자 ≥ 최대 인구의 60%).

## 2. 핵심 루프

하루 = 5단계 + 자동 밤 정산. 평균 2~2.8분(비원정일 ~2분 / 원정일 ~5분 / 밀폐일 ~1.5분). 매 새벽과 원정 사건 선택 직후 자동 저장(난수 상태 포함).
1) 새벽 장부(20초): 오늘 청구서 + 3일 예보(수신 설비 6일) + 물때 D-카운트 + 상태 변화 3줄. 예) Day 30(인구 10, 사용 칸 10): 식량 10+물 10+난방 7+유지비 5 → 청구 32 / 예보 D33 약탈 R≈45(경비 4~5명), D34 공물②. 물때 3회는 Day 1 달력에 빨간 표시, 총 필요량 추정을 한 줄로 공개(필터 40±8, 물 115±15).
2) 다이얼 2개: 배급 정량 1(스트레스 0) / 풍족 1.75(−2). 난방 보통 / 절약 ×0.6(+2). 절식은 다이얼에서 빼 비상 조치(판당 최대 5일: 식량 0.5, 스트레스 +4, 발병 +3%p)로 옮김 → 지배·자살 다이얼 제거.
3) 배치(30~60초): 역장 제외 주민마다 자리 1개(수색·연료·쥐덫·물·정수기·버섯·작업대·조제·간호·경계·연구·건설·회복 시설·정비·환기구 보수·휴식·원정). 산출 = 기본 × (1+0.10×(관련 기술−2)), 직군 일치 +20% [제안, 시뮬 추가]. 합격선: 같은 자리에 최선/최악 인물을 넣으면 산출 차 ≥ 40%. 휴식 = 산출 0, 스트레스 −12, HP +2(일반 +1), 발병 ×0.5. 「어제와 같이」(이름까지 복사)·「부족분 추천」(자리 수와 후보 상위 3명을 보여 주고 1탭 적용) 제공. 추천 로직은 engine의 autoAssign(state, mode) 한 함수: ①물·식량 청구 ②경계 인원(예보 R) ③간호(환자/2) ④연료·고철 ⑤휴식 순.
4) 원정(선택, 2~5분): 편성 2~3명 → 가방 → 목적지 → 5층 노드(층마다 사건 1장) → 층 사이 계속/철수 → 귀환. 처리 순서 고정: 출발 확정 스냅샷 → 원정 플레이(기지 정지) → 귀환 시 부재 2일치를 autoAssign(경비 우선)으로 자동 정산하고 로그 3줄 요약 → 귀환 효과 적용. 출발 화면에 부재 2일의 약탈 R, 남는 경비 가능 인원, 예상 결과 3단계를 보여 주고 습격이 겹치면 「원정 연기」를 항상 제공.
5) 저녁 화로 대화(30~40초): 2칸(빛 신조 +1칸). 후보 카드 4장 중 2명에게 경청/격려/맡김 중 하나. 숨은 선호 일치 −15·유대 +1 / 보통 −8 / 어긋남 −2(수치 동결). 선호는 고통·상실·미덕 직후 40%로 재추첨(외우면 끝나는 잡무 방지).
6) 밤 정산(자동, 순서 고정): 생산 → 배급 → 난방 → 유지비 → 부패·상한(지출 후 재고 기준) → 달력 사건(습격·공물·유행) → 쪽문/밤 사건 1건(매일 1장, 밀폐 중엔 밀폐 사건 1장) → 스트레스·부상·질병·고통/미덕 → 이별 확정(명부 줄 긋기 2탭, 확인 1단계).
■ 역장은 일·원정을 하지 않고 1인분만 쓰며 화로 대화와 결정을 맡는다. 원정 사망·이탈은 전부 이름 있는 주민의 일이다.
■ 입력량 합격선: 하루 평균 ≤14탭, 최대 ≤24탭(dispatch 호출 수로 자동 측정). 되돌릴 수 없는 탭(철수·줄 긋기·☠ 선택)에는 확인 1단계.
■ 첫 5분: 0:00 멈춘 전동차 프롤로그 4장면(기존 재사용) → 3번째 장면이 3층 튜토리얼 원정(HP 1 하한). 후보 4명(순례·서하·기철·마리) 중 3명만 데리고 나오고 남은 1명은 D4~6 쪽문 사건으로 돌아올 확률 50%(공개), 아니면 영구 소실. 랜턴 선택은 오래 남는다: 어둠=고철 +6, 서하 스트레스 +15 시작 / 밝게=연료 −6, 기철 유대 +1. 2:30 명부에 이름 쓰기 → Day 1 장부(시작 식량 20·물 12·연료 16·고철 14·약품 2, 쥐덫 구역 1개 시작 시설) → D6 약탈 예보를 보고 경비 2명이 일손 절반임을 깨닫는다. [시작 재고 하향은 재측정]
■ 길이 추정(구현 후 자동 플레이로 실측): 약 2.5~3시간.

## 4. 위협 스케줄

원칙: 위협은 '지금 무엇을 포기할지'를 고르게 하는 모양으로 온다. 전부 달력에 있고 3일 전부터 예보(유형 표시, 규모 ±20%, 수신 설비면 정확값). 치명 선택지는 ☠와 확률을 미리 공개.
■ 상시 압박
- 한파: 난방 = ceil((0.3×인구 + 0.2×사용 칸 + 0.2×신조 방 수) × 계수) × 다이얼. 계수 D1~7 1.0 / D8~20 1.1 / D21~35 1.4 / D36~50 1.7 / D51~60 2.0. (신조 방은 칸 상한은 안 쓰지만 난방엔 들어간다.)

## ADR에서 남김/버림/새로 바꿈

■ 남길 것
- 희소성→위협→병목 이동 구조와 단계가 열리는 느낌, 재료를 먹는 변환(필터 제작·버섯 재배·조제), 보급량=원정 거리(가방 칸), 창고 상한과 가격 상승(숙소 ×1.25), 도둑·병·상인 같은 압박과 선택(맞서기/숨기기/협상), 건조한 로그 톤, 하루 단위 진행.
■ 버릴 것
- 불 지피기→낯선 사람→건축가→직선 건설의 첫 5분, 클릭·쿨다운 연타, 실시간 틱 방치형, 이름 없는 일꾼 숫자, 놀리는 생존자의 공짜 수익, 한 번에 다 살 수 있는 단일 직선 목록, 5구역 1회성 순회와 장르 전환 후 단일 결말.
■ 새로 바꿀 것
- 루프: ADR '모은다→짓는다→늘린다' ↔ 이 게임 '읽는다(장부)→배분한다(사람=일손=마음)→대화한다→원정으로 메운다→물때를 견딘다'.
- 첫 5분: 불이 아니라 3명만 구하는 튜토리얼 원정, 랜턴, 이름 쓰기, 장부, 화로 대화.
- 위협: 달력의 약탈 11·공물 3·유행 2·물때 3. 쌓아 둘수록 더 털리는 노출 비례 약탈.
- 테크: 칸 14 한도, 신조 18노드 중 점수 6·트랙 2/3·A/B 택1, 부품(원정 전용)·청사진(가보 자리), 판마다 겨울 성격이 정답 트랙을 바꿈.
- 원정: 2~3인 파티, 가방 칸 선택, 5층 노드, 랜턴 3단, 4단계 판정, 후퇴 판단, 조건 태그 사건, 결과가 상처·소지품·플래그로 이월.
- 주민: 이름 있는 개인(특성·스트레스·유대·소원·영구 이별·유품)과 명부 낭독 엔딩.
- 남은 약점(정직하게): 시설-건물 대응이 일부 남음(숙소=오두막, 보관함=수레)이라 이름과 동사를 바꾸었고, 후계 교대(구조 전환 장치)를 1.0에서 뺐기 때문에 후반 새 동사는 사절·최후의 밤 3단·신조 T3에 의존한다.

## 서울 2033 확인 못 한 점

근거로 삼은 것은 브리프가 '확인됨'으로 표시한 3가지뿐이다: ①핵전쟁 후 폐허 서울의 텍스트 로그라이크, 사건 카드 350여 개 이상 ②선택의 결과로 능력·보상 또는 상처·스트레스를 얻고 이후 모험에 영향 ③능력·아이템·돈·체력을 관리하고 선택지가 가진 능력·소지품에 따라 열리고 닫힘. 이 틀에서는 '조건 태그 + 결과 3곳 저장'으로만 옮겼다.
가정했거나 몰라서 서울 2033의 특징이라고 단정하지 않은 것(확인 필요):
1. 지하철역 대피소 운영·일손 배치·물때·신조 트리·칸·부품 게이트·명부는 전부 《어두운 역》의 창작이다. 서울 2033에 기지 운영이나 주민 로스터가 있는지 모른다.
2. 사건 카드의 구조(상황+선택지+조건+결과), 성공률 공개 여부, 판정이 확률인지 수치 비교인지 모른다. 4기술·4단계 판정·성공률 공개는 우리 설계다.
3. 상처·스트레스가 수치인지 상태 이름인지, 종류와 회복 방법을 모른다. 0~100 스트레스, 고통/미덕, 후유증은 DD 구조를 빌린 자체 설계다.
4. 방독면·필터 같은 소모품 규칙, 거래 규칙, 이동 구조(지도 노드/선형)를 모른다. 필터·가방 칸·노드 그래프는 우리 창작이다.
5. 돈이 있다는 것만 확인됐고 화폐 경제는 모른다. 돈 없이 물자 교환(고철 40=부품 1)으로 대체했다.
6. 영구 사망, 파티 편성, 사건 연쇄, 350개 이상 카드의 구성 방식(템플릿/손저작)을 모른다. 영구 이별·2~3인 파티·체인·템플릿 조합은 DD와 우리 쪽 설계다.
7. 1.0의 원정 사건 약 58장(구역 30+랜드마크 5+공용 12+소원 지점 8+튜토리얼 3)과 밤 사건 28·밀폐 10이 350여 장 체감을 주는지는 알 수 없다. 장소 12·상황 10·트위스트 8 조합은 최대치이며 1.0에서는 구역별 직접 저술 중심이다.
8. DD의 횃불 설명(브리프: 낮은 빛=적이 강해지고 약탈이 늘지만 스트레스는 낮음)과 달리 우리 랜턴은 어둠에서 스트레스가 오른다. 원작과 같다고 주장하지 않고 위험↔보상 레버라는 취지만 가져왔다.
사용자에게 물을 것: 서울 2033에서 기억에 남는 사건 카드 1~2장(상황·선택지·결과의 이어짐), 상처·스트레스가 화면에 어떻게 표시됐는지. 답을 받기 전에는 사건 엔진을 확정하지 않는다.
