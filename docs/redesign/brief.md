# 어두운 역 — 재설계 공통 브리프 (2026-10-20)

모든 역할(세계관·게임 디자인·콘티·레벨 디자인·아트 디렉션)이 같은 전제에서 출발한다. 이 문서를 먼저 읽고 자기 몫을 쓴다.

## 왜 다시 하나 (사용자의 말, 그대로)
- "게임 디자인 처음부터 다시 해야 할 것 같아."
- "사람들 인게임 그래픽이나 소모품 같은 것도 너무 커. **픽셀 던전 느낌이 너무 강하게 나.**"
- "디자인부터 콘티, 레벨 디자인, 세계관부터 에이전트로 나누고 일해 보자."

해석: 지금 v3는 48px 타일을 폰에서 2~4배로 키워서 한 화면에 7칸 정도만 보이고, 사람 하나가 화면 높이의 1/6을 차지한다. 그 결과 '로그라이크 던전 탐험기'(Pixel Dungeon)처럼 보이고, 사용자가 원한 '어두운 쯔꾸르풍 이야기 게임'(RPG Maker 호러, Fear & Hunger, 서울 2033의 사건 카드 감성)에서 멀어졌다. 그래픽 크기는 증상이고, 화면 구성·지도 구조·하루의 흐름까지 같이 다시 잡아야 한다.

## 지킬 것 (사용자가 직접 골랐거나 좋아한 것 — 버리지 않는다)
1. 무대: 서울 2호선 을지로입구역. 그날 아침 하늘이 안쪽에서 열렸고, 잿빛 안개가 이름을 불러 사람을 데려간다. 지하가 그나마 안전하다.
2. 바깥 신들 7 (docs/gods_design.md): 적대 네레흐「바닥의 어미」·구르마흐「빈 입」·세엘「세는 자」 / 중립 테르미아「검표원」·오스렌「잿빛 손」 / 우호 히스카「작은 불」·호「부르는 소리」. 신은 괴물이 아니라 **배울 수 있는 규칙**이다.
3. 혼자 깨어나는 오프닝 (docs/storyboard_opening.md 개정 2): 텅 빈 전동차 → 운전실의 명부 수첩 → 터널에서 정비사 기철 → 역의 다섯 사람.
4. 이름 있는 사람 6명 (순례·서하·기철·은지·동하·마리) + 동료 2 (약사 은채, 배수 정비공 도현). 소원·영구 상처·붕괴·기억이 사람마다 쌓인다.
5. 톤: A Dark Room의 건조함 + Fear & Hunger / Darkest Dungeon의 어둡고 적나라함. 수위는 '극단까지'(식인 선택 포함). 단, 성폭력·자해 묘사는 넣지 않는다.
6. 원칙: **판단할 정보는 친절하게 보여 주고, 선택의 대가는 가혹해도 된다.**
7. 플랫폼: 브라우저(폰 세로 화면 우선), 순수 JS, 빌드 없음. 그림은 Codex image_gen으로 생성(11/7까지 가능) → 파이썬으로 도트화. 엔진은 v2(순수 JSON 상태, dispatch) 재사용 가능.
8. 사용자 결정(2026-10-20): D10에 주인공이 탈지는 플레이어가 고른다 / 통로는 필수가 아니다(도보 경로) / 소원 중 3명(기철·순례·서하)은 비극으로 끝난다.

## 다시 생각할 것 (전부 열려 있다)
- 화면 구성과 그림의 크기·비율 (가장 급함)
- 하루의 흐름과 핵심 루프, 자원·일·위협의 수
- 지도의 수와 구조 (역·원정 지역·손으로 만든 지도 vs 무작위)
- 10일이라는 길이와 3막 구조
- 이야기의 진실을 어떤 순서로 드러낼지
- 어디까지가 1막(이번 판)이고 어디부터가 다음 막인지

## 산출물 규칙
- 한국어, 쉬운 말. 사용자는 코드를 거의 안 쓴다 — 전문 용어는 풀어 쓴다.
- 자기 파일 하나만 쓴다 (docs/redesign/<역할>.md). 코드·그림·다른 문서는 건드리지 않는다.
- 길이: 150~300줄. 표와 목록 위주. 결정이 필요한 것은 끝에 "사용자에게 물을 것" 3개 이하로.
- 다른 역할과 겹치는 부분은 "→ <역할> 문서 참고"로 넘기고 반복하지 않는다.
- 확신이 없는 수치는 [제안]으로 표시. 측정이 필요한 것은 "재는 법"을 적는다.
