# 어두운 역 — 설계 v5 (다섯 역할 통합안, 2026-10-20)

다섯 문서(docs/redesign/ world·gamedesign·storyboard·level·art)를 한 장으로 합쳤다. 세부는 각 문서, 여기는 **결정과 충돌 해결**만. design_v4는 이 문서로 대체한다.

## 0. 한 줄 요약

> 역은 **걸어 다니는 집**(32px 쯔꾸르 크기, 한 화면 12칸), 밖은 **손으로 만든 작은 장소**와 **장면 그림 + 카드**. 열흘 동안 같은 장소가 조금씩 변하고(핏자국·물·안개·분필·무덤), 당신은 기관사의 명부 수첩에 여섯 이름을 적어 넣는다.

픽셀 던전 느낌의 원인 넷을 전부 고친다: 타일 48→32·화면 7→12칸 / 검은 테두리 → 그 물체의 어두운 색 / 둥근 시야 → 넓은 어둠과 빛 두 개 / 무작위 방+복도 → 손으로 만든 장소.

## 2. 충돌과 해결

| # | 어긋난 곳 | 해결 |
|---|---|---|
| 1 | **원정 걷기**: 게임 디자인은 "역만 걷고 원정은 장면+카드", 레벨은 원정 8장을 손으로 그려 걷게 함 | → **사용자 결정 A**. 추천은 절충: 역 + 원정은 지역마다 **2층**(1층 길목, 2층 보스)을 손 지도로 걷는다. 깊이 3은 2로 줄여 엔진(maxDepth 2) 그대로 |
| 2 | 오스렌: 세계관은 이번 판에서 빼자, 콘티·디자인은 조연으로 둠 | → **빼되 데이터는 남긴다**(코드의 GODS는 그대로, 등장만 막음). 시신 처리 선택은 유지. 뼈 줍는 이는 이름 없는 보스 |
| 3 | 순찰대 입구: 콘티는 출구 계단, 세계관은 지하상가 셔터(안개 규칙상 계단은 불가) | → **지하상가 통로(개찰구 쪽)**. 콘티 3-1 장소를 고친다. 순찰대 = 은채의 '병원 팀'과 같은 무리 → 협정 여부가 D8 태도를 가른다(게임 디자인에 추가) |
| 4 | 안개 구역(C): 레벨은 지상 광장까지, 세계관은 "안개 = 하늘이 보이는 자리"라 광장 전체가 안개여야 함 | → **지하보도 안에서 끝낸다**. C2를 '을지로 지하보도 상층'으로 바꾸고 지도 모양은 그대로(안개 선이 위에서 내려옴). 바깥 풍경 그림이 필요 없어져 Codex 부담도 준다 |
| 5 | 글자 크기: 아트는 19→17 축소 제안, 사용자는 방금 "너무 작다" | → **19/18/16 유지**. 그림이 작아져도 글은 줄이지 않는다 |
| 6 | 시설: 디자인은 버섯 재배 삭제, 레벨은 재배·치료 자리 G 둘 다 | → 재배 삭제. G 자리는 **진료소 하나** |
| 7 | 결말 등급: 디자인은 명부 점수 5등급, 콘티는 지금 엔진 조건 | → 디자인 공식. 콘티의 마지막 컷 글은 등급 이름으로 그대로 붙인다 |
| 8 | 플레이어 이름: 콘티는 입력 여부를 물음, 세계관은 검표원이 이름을 읽는 장면이 있음 | → **입력 받는다(비워 두면 '당신')**. 명부·방송·검표에서 그 이름이 읽힌다 |

## 3. 사용자 결정 (2026-10-20)

| 항목 | 결정 |
|---|---|
| A. 원정 걷기 범위 | **역 + 원정 지역마다 2층 손 지도**(1층 길목, 2층 보스). 지도 6장(A1·A2·B1·B2·C1·C2) |
| B. 주인공 정체 | **당신이 이 열차의 기관사였다.** 직접 말하지 않고 단서 3(맞는 구두·기철의 한마디·검표원의 호칭)로만 |
| C. 비극 소원의 끝 | **실제로 떠날 수 있다, 플레이어 선택으로만.** 기철(명단을 읽어 주면 계단을 올라 재가 됨, 완력 판정으로 막을 수 있음)·순례(보내 주면 올라감). 되돌릴 수 없음 |
| D. 전투 | **보스 3번만**(뼈 줍는 이·익사자 무리·세는 아이). 잡몹은 카드 선택지 '맞선다/피한다'. 부위 전투 화면은 보스 전용, 크리처 128px |
| 제가 정한 것 | 오스렌 제외(되돌릴 수 있음) · 도트 1px · 크리처 전투 그림 128 · 이름 입력(선택) · 안개 구역 포함, 지하보도 안 · 역 구역 날마다 열림 · 원정 지형 고정(무작위는 사건 자리와 카드만) · 결말 "영" 한 줄 허용 · 글자 19 유지 |

## 4. 만들 순서 (통합)

| 단계 | 내용 | 크기 | 끝났다는 증거 |
|---|---|---|---|
| **1. 보이는 것부터** ✅ 10-20 | art §5 파이프라인 수치 바꾸고 build_art.sh로 전부 다시 자름. art3.js S=2, game.js 배율 1.0·어둠·빛, 외곽선 색, 안개 겹. 역 지도를 level §2의 28×16으로 교체(구역 잠금 포함). 일 7종·상한 16·재배 삭제 | 중 | 폰 캡처: 사람 높이 = 무대의 1/14, 가로 12칸. 한 판 완주 |
| **2. 장소** | 원정 손 지도(결정 A에 따라 4~6장), `layers`(날·상태별 덮어쓰기), 장치 5(핏자국·물·안개·분필·무덤), tools/mapcheck.js | 대 | mapcheck 전부 통과, 하루 걷기 25초 이하 |
| **3. 이야기** | 명부 수첩 이름 입력, 기관사 단서 3, 콘티 컷 A~L대로 장면 재구성, 새 장면 그림 4, 신 규칙 메모(이미 있음) 다듬기, 순찰대 입구 이동 | 중 | 고정 사건 6개 100% |
| **4. 결정** | 아침 갈림길 카드 10장, 저녁 '누구 곁에', 소원 3단계(6명, 비극 3), 봇 정책 '자원/시선' 추가 | 대 | 카드별 점수 차 ≤1, 소원 1~3개 |
| **5. 열차** | 정원 = 표+운임+약속, 도보 경로, 명부 점수 5등급, 낭독 결말, 당신의 선택 2벌 | 중 | stay 정책 정원 0 ≤10% |
| **6. 보스** | 랜드마크 3 + 전투 128px 장면, 소원 물건 | 중 | 신 징조 판당 ≥3, 사망 0.8~1.5 |

그림 주문(Codex, 11/7 전)은 1단계와 3단계에 몰린다: 큰 소품·바닥 장식·반응 표시·안개 겹·가장자리 타일(5시트) + 장면 4장(수첩 클로즈업·수첩 대조·열린 열차 문·안개 구역). 전부 합쳐 약 10번 주문.

## 5. 합격선 (gamedesign §6 그대로)
고정 사건 100% / 사망 0.8~1.5 / 정원 0 ≤10% / 결말 분포 / 갈림길 점수 차 ≤1 / 소원 1~3 / 결정 수 35~50·40~60분·하루 걷기 20걸음.
