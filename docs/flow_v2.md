# 어두운 역 — 전체 흐름 v2 (검수 반영, 2026-10-21)

flow_v1을 스토리 담당(docs/review_flow_story.md)과 인터랙션 담당(docs/review_flow_ux.md)이 검수했다. 방향(강요 없음·발견)은 둘 다 동의. 세부 수정 11건, 반대 1건을 반영한 확정 흐름이 이 문서다. 다음은 이대로 만든다.

## 0. 원칙
1. 플레이어가 하고 싶은 것을 막지 않는다. 길을 막는 토스트·자동 열림·자동 대화·OS 확인창은 없앤다.
2. 세계가 먼저 거기 있고, 플레이어가 발견한다. 정보는 조사물·사람 한마디·밤 보고서 세 겹으로 흘러들어 **안 가도 늦게는 안다.**
3. 당신은 다치지 않는다(세계 규칙). 실패의 값은 물건·시간·남의 몸.
4. 그림은 **무대 위에**, 글은 **상자 안에**. 상자 높이는 늘 같다.

## 1. 프롤로그 — 확정 흐름

| 단계 | 확정 | 단서(가시성) |
|---|---|---|
| 검은 화면 | 지금 그대로. 18+ 안내는 타이틀로 | — |
| 전동차 | **레버를 당기면 문이 바로 열린다**(물 +2, 찬 공기). 가방·운전실·구급함·무전기·**수첩**은 전부 선택 조사물. 하나를 봐도 나머지가 사라지지 않는다 | 운전실 쪽에서 무전기 잡음이 들린다. 수첩은 계기판 위 **밝은 점**(광원) |
| 수첩 | 계기판 위 조사물. 주우면 "이름이 적혀 있다 — 당신은 이 열차에 탄 기억이 없다" + Tab 수첩이 열린다. **놓치면** D1 아침 기철이 내민다: "당신 거요. 이름이 있소." 두 마디, 어디서 났는지 말 안 함, 헤드램프를 바닥으로. 신뢰 변화 없음(그가 뭔가 안다는 첫 단서) | — |
| 터널 | 기철은 잔해 앞에 **서 있고 헤드램프가 터널의 유일한 빛**. 가까이 가면 머리 위 **말풍선** "거기 서."(토스트 아님). **말을 걸면** 대화·선택 3("잔해 너머가 을지로입구요. 불빛이 보였소"). 말 안 걸고 잔해를 조사하면 **"혼자 넘어 본다(완력) / 그만둔다"**. 실패 = 가방이 찢겨 생수 한 병이 굴렀다(물 −1), 다시 할 수 있다. 성공하면 뒤에서 말풍선 "…위는 보지 마시오." | 헤드램프 광원, 말풍선 |
| 기철을 지나치면 | D1 아침 역으로 혼자 온다. 헤드램프가 당신 얼굴에 멈췄다 내려가는 컷은 **이 도착 장면**에 둔다(얼굴을 안다의 씨앗) | — |
| 승강장 | 카드 "을지로입구역" → 역 지도. **순례 하나**가 화로 옆. 첫 줄 "신발 신었어? …됐어, 사람이네." 둘째 줄 "저쪽 끝에 하나. 역무실에 하나. 안 나와." 그 뒤는 **플레이어가 간다**: 계단 앞 3컷(재가 된 다리·구두·안개 벽), 스피커 앞 3컷(녹음, **숨을 쉰다** — D7과 대비), 마리 잠자리 2컷. 열흘 약속 선택지는 없다 | 계단의 잿빛, 스피커 지직, 잠자리의 사람 |
| D0 저녁 | 수첩에 이름을 적는다 — **발견한 사람만**(순례·마리, 기철이 같이 왔으면 셋). 적을 때 순례가 묻는다: "자네가 적어? 그럼 자네가 데려가는 거야." [데려가겠습니다 (힌트: 소리 내어 한 약속이다) / 말없이 적는다] — 되물음이지 강요가 아니다. 이것이 **약속 1**(손등 구멍 첫 후보) | — |

## 2. 사람 발견 — 확정 순서

| 사람 | 언제 | 어디·단서 | 발견 장면(4컷 이내, 글은 review_flow_story §5) | 안 가면 |
|---|---|---|---|---|
| 순례 | D0 | 화로 | 위 | — |
| 마리 | D0 | 승강장 끝 잠자리, 앉아 있다 | 2컷 | D1 밤 보고서 "승강장 끝에서 누가 밤새 이름을 외웠다" |
| 기철 | D0 터널 / D1 아침 | 터널 또는 발전기 옆 도착 | 4컷 | — (반드시 온다) |
| 은지·동하 | D1 아침 | 지하상가 셔터 **두드리는 소리 + 셔터 틈 흔들림**. 조사하면 "연다 / 두드린다 / 둔다" | 4컷 | D2 아침 순례가 연다 |
| 서하 | **D2 아침** (순례가 열쇠를 넘긴다 = "자네가 열어") | 역무실 문. **문 틈에 담요 자락, 안은 소리가 없다**(휴대폰 불빛 ✗ — 서하는 화면을 안 켠다). 순례 "밥은 문 틈으로 넣어." | 4컷 | D3 아침 순례가 연다("어젯밤 소리에 애가 문을 긁었어") |

- 엔진: 주민 `status: 'away'` → 발견 때 `home`. 일손 D0 2~3명 → D2 6명. 예산은 봇으로 다시 잰다(D1·D2는 사람이 적어 식량 수지가 좋아진다 — 의도).
- **명부는 발견한 저녁마다 한 줄.** "여섯 줄이 찼다. 당신 글씨였다."는 마지막 줄을 적은 저녁(보통 D2). 동하의 반 박자는 D1 저녁.
- 화면: 패널에 사람 수 숫자 없음. 수첩 명부 줄이 는다, 게시판 칩 2→4→6. 발견 순간은 걸어 들어오는 모습 + 한 줄 + 토스트 "명부에 한 줄 — Tab". 종·카드 없음.
- 서하는 D2 아침 발견이라 **D2 원정 동행 가능**. 세 비극(순례 D5·기철 D6·서하 D7~8)과 소원 1단계 시점은 그대로.

## 3. 하루 — 확정 변경

| 단계 | 확정 |
|---|---|
| 출구 | 밟으면 띠에 "지하상가 통로 — 조사하면 원정". **조사해야** 준비 창. 준비 창의 보급 ±1 버튼 6개는 "식량 4·물 4 (바꾸기)" 한 줄로 접는다 |
| '!' | 밟기 → **조사**로. "무언가 있다 — N시간" 확인창은 **뺀다**(시간은 패널에 있다). 동행 멈칫은 던전에 동행 스프라이트가 없어 **2단계(손 지도)에서** |
| 저녁 | 목록을 없앤다. 사람들이 화로 둘레에 앉고, 말 걸 수 있는 사람 머리 위에 '…'. 호버에 "스트레스 17 → −8 · 신뢰 ●○○○"(목록이 주던 판단 정보). 말 걸고 나면 '…'이 전부 꺼진다. **화로 조사 = 밤**(띠: "저녁 — 한 사람과 이야기할 수 있다 · 화로를 조사하면 밤") |
| 확인창 | OS `window.confirm`은 전부 없앤다. 되돌릴 수 없는 것(오늘 밤 사망 예고·승차 확정·저장 지우기·식인)만 **상자 안 2단 선택**("그래도 보낸다"). 공사 착공·힌트 있는 선택지는 부제의 ⚠로 충분 |
| 게시판 | '오늘' 탭(배치·추천)과 '예보' 탭으로 |
| 밤 보고서 | 달라진 것만 + 잃은 것 한 줄(틀 v6.1) |

## 4. 일러스트 — 확정 규칙 (A안: 그림은 무대, 글은 상자)
- 측정(인터랙션 담당): 상자 상한은 252. 한 줄 창은 스크롤이 아니라 **글이 64px 기둥에 찌그러진다**(.cg flex 버그). 선택지 창(약속 413, 결말 522)은 스크롤.
- **장면 그림은 #stage 위의 층**(지도 위에 384×216을 가운데에, 지도는 어둡게). 글은 아래 상자에 350px 너비로. 상자 높이는 늘 같다. 그림은 **다음 그림이 올 때까지 유지**(지금은 첫 문장 뒤 사라진다).
- 선택지 창: 그림 256×144를 왼쪽 위, 글은 옆(194px), 선택지는 아래 → 280 < 350, 스크롤 없음.
- 결말·타이틀: 무대 층 384×216.
- 어느 장면에 그림이 있어야 하나(스토리 담당 §4): 있어야 23장, 없어도 44장(원정 반복 장소·밤 카드·강림·상태). 새 그림 최대 3(셔터 틈·역무실·수첩 클로즈업).
