### 신을 "안 보이게" 두는 법
| 지금(프로토타입) | v2 |
|---|---|

### 금기 · 지리 · 아는 것 / 모르는 것
| 항목 | 내용 |
|---|---|
| 금기 (세계) | 위에서 부르는 이름에 대답하지 마라 / 밤에 불을 크게 하지 마라 / 물에 든 사람을 당기지 마라, 버리지도 마라 / 지키지 못할 약속을 소리 내지 마라 — **전부 사람 입으로만**, 어긴 값은 몸으로 |
| 금기 (제작) | 성폭력 장면·자해 장면은 화면 밖·간접. 그 외(살인·식인·시체·고문·배신·버림)는 장면으로 직접 |
| 지리 | 을지로입구역 한 장(허브 화로) + 지하상가(A, 2층) + 배수로(B, 2층). 안개 계단은 역의 벽. 셔터 너머에 **더 큰 무리**(순찰대 = 은채의 '병원 팀') |
| 시간 | 열흘. 정오·밤·안개 칸·수위는 당신 사정을 모른다 |
| 아는 것 (열흘 끝) | 대답하면 간다 / 빛·소리가 안개를 부르는 **것 같다** / 물이 높으면 깬다 / 열차는 약속이다 / 운임은 사람마다 하나 |
| 모르는 것 (끝까지) | 하늘 안쪽 / 간 사람의 행방 / 왜 당신 이름이 명부 첫 줄인지 / 왜 당신이 열차에 탄 기억이 없는지 / 고지대가 안전한지 / 셈이 "+1"인 이유 |

**장면 2 글 (수위 견본)**
선로에 사람이 걸려 있었다. 얼굴은 물에 불어 있었고, 한쪽 신발이 없었다. 마리가 손목을 잡았다. "하루는 안 됐어요." 은지가 통조림 빈 깡통을 발로 밀었다. "고기야." 아무도 반박하지 않았다. 마리가 가운에서 칼을 꺼내 허벅지 안쪽을 갈랐다. 노란 기름이 먼저 나왔다. 동하가 드럼통에 장작을 넣었다. 냄새가 났다. 순례는 벽을 보고 앉아 있었다. 당신 배에서 소리가 났다.
[선택] 받는다 / 받지 않는다 / 칼을 빼앗는다 (완력 — 실패: 마리가 당신 손등을 긋는다)

**장면 3 글**
셔터가 반쯤 올라가 있었다. 기철이 그 밑에 엎드려 있었다. 왼손 손가락 셋이 반대로 꺾여 있었고, 헤드램프 유리가 바닥에 깔려 있었다. 횃불 든 남자가 기철의 머리를 밟고 있었다. "열쇠." 기철이 입을 열지 않았다. 남자가 발을 비볐다. 동하가 소리쳤다. "내가 말했어요. 창고. 내가." 은지가 기둥 뒤에서 나오지 않았다.
[선택] 열쇠를 내준다 / 동하와 함께 덤빈다 (완력 둘 — 실패: 동하 중상, 당신 경상) / 아무것도 하지 않는다

**장면 4 글**
새벽에 눈을 떴다. 기철의 담요 위에 마리가 앉아 있었다. 베개를 두 손으로 누르고 있었다. 기철의 발이 두 번 움직이고 멈췄다. 마리는 베개를 치우고, 기철의 눈을 감기고, 이름을 불렀다. "박기철 씨." 또 불렀다. 계단 쪽에서 재가 흘러내리는 소리가 났다. 동하가 담요 속에서 눈을 뜨고 있었다. 당신과 눈이 마주쳤다.
[선택] 일어난다 / 눈을 감는다 / 수첩을 꺼낸다

| 시간 | 열흘. 정오·안개·수위·순찰대 날짜는 고정. 기다려 주는 사건 없음 |
| 실패의 뜻 | 당신이 굶어 죽거나 맞아 죽거나 대답해서 올라가면 → **그 자리에서 끝**, 수첩을 주운 사람이 명부를 읽는다. 되감기·슬롯 없음, 자동 저장 하나. 전멸도 결말이다 |
| 심판 없음 | 유대·스트레스·신뢰·카르마 **표시 없음**. 판단 정보는 행동으로만: 눈을 피한다, 자리를 옮겼다, 밤에 안 잔다, 그릇을 안 비웠다 |

### 주민 간 사건이 당신 없이 일어나는 방식 (엔진 관점, 한 단락)
주민마다 **욕구 넷**(배고픔·목마름·두려움·애착 대상)과 비밀 플래그가 있다. 밤마다 시드 난수로, 주민 쌍마다 사건 표를 굴린다 — 조건은 욕구 문턱과 세계 시계(안개 칸·수위·순찰대 날짜)뿐이고, 당신이 어디 있었는지는 조건이 아니다. 결과는 두 가지로만 남는다: **흔적**(물건 상태 — 빈 물통, 옮겨진 담요, 피 묻은 베개, 뜯긴 상자)과 **소문**(목격자 한 사람의 한 줄, 거짓일 수 있다). 아침 보고서는 "당신이 볼 수 있었던 것"만 적고, 나머지는 걸어가서 조사하거나 말을 걸어야 안다. 수치는 봇만 본다. 합격선 [제안]: balanced 봇 열흘에 주민 간 사건 ≥ 6, 그중 플레이어가 흔적으로 발견하는 비율 50~70%, 끝까지 모르는 사건 ≥ 1.

### 수첩이 사실만 적는 방식
| 규칙 | 예 |
|---|---|
| 본 것만, 물건·때·사람 | "D2 밤. 서하 물통 빔. 순례 입술 터짐." |
| 동기·판단 금지 | "기철이 훔쳤다" ✗ → "기철이 눈을 피함" ○ |
| 추측은 뒷장에 "~같다"로, 플레이어가 두세 문장 중 고른다 | "불을 켠 다음 날 재가 내려오는 것 같다" |
| 지우지 못한다. 틀린 줄도 남는다 | 다음 판에 그대로 이월 |
| 명부 줄은 날짜만 — 사인 칸은 빈칸으로 둘 수 있다 | "박기철 — D8 밤 ___" |

### 전투 (있다) — 안

### 숨은 정체 — 카르마 없는 카르마 (수치·선악 표시 없음)
| 축 | 움직이는 결정 (한쪽 ↔ 다른쪽) |
|---|---|
| **몫** | 자기 그릇을 비운다·자리를 내준다 ↔ 자기 그릇을 먼저 채운다·운임을 자기 몫으로 |
| **손** | 본 것에 개입한다(칼을 빼앗는다·덤빈다·추궁한다) ↔ 보고 적기만 한다 |
| **이름** | 이름을 부른다·대답한다·위로 부른다(밀고) ↔ 침묵한다·"거기"라고만 |

| 정체 후보 | 축 조합 | 결말에서 밝혀지는 법 |
|---|---|---|
| **기관사** | 몫 내줌 + 손 개입 | 차장: "다시 모시겠습니까." 운전석에 당신 구두 한 짝. 명부 첫 줄 옆 '을지로입구'는 당신이 정차시킨 역 |
| **승객** | 몫 챙김 + 손 적기만 | 차장이 당신에게도 '님'을 붙인다. 운전석은 비어 있고 다른 사람이 앉는다. 명부 첫 줄은 **그냥 탄 순서** |
| **검표원** | 손 적기만 + 이름 침묵 | 차장이 당신 수첩을 돌려받는다 — 같은 수첩이었다. 펀치가 당신 손에 있다. 명부를 읽는 사람이 당신 |
| **센 자** | 이름 부름·밀고 + 몫 챙김 | 차장이 당신 이름을 **읽지 않는다**. D3 셈의 "+1"이 당신이었다. 당신은 신발을 벗고 계단을 오른다. 수첩은 남은 사람이 읽는다 |

숫자 없이 "쌓인다"를 느끼게: ① **호칭** — 순례 "자네" → "기사 양반" / "손님" / "적는 사람" / (센 자 쪽이면) 이름을 안 부른다 ② **꿈** D4·D6·D8 밤 한 컷 — 운전석 / 좌석 / 개찰구의 펀치 / 계단 위에서 내려다본 승강장 ③ **운전실 유리창** 조사 글이 바뀐다("모자 쓴 사람" → "아무도 없다" → "세고 있다") ④ 세는 소리가 당신 차례에 "…넷?"으로 멈칫하는지, 그냥 지나가는지 ⑤ 차장의 '님'. 축 값은 저장에만 있고 봇만 본다. 수첩 이월은 정체를 적지 않는다 — 다음 판 D0 "뒷장이 두껍다"만.
