# 어두운 역 — "보통 게임처럼" 점검표 (2026-10-21)

사용자: "일반적인 게임들에서 보이지 않을 문제점들이 보여. 실 사용감·가시성·개연성·자연스러움을 고려해야 해."
원인 셋: ① 새 규칙을 쌓기만 했다 ② 화면이 폰 세로 기준이었다 ③ 문서가 코드보다 앞서 달려 서로 어긋났다.
앞으로 모든 기능은 이 네 잣대를 통과해야 들어간다. 통과 못 하면 **빼거나, 세계 안에서 설명하거나, 보통 게임의 방식으로 바꾼다.**

## 네 잣대
| 잣대 | 질문 | 보통 게임의 답 |
|---|---|---|
| 실 사용감 | 하고 싶은 것을 한 번에 할 수 있나. 한 일의 결과가 바로 보이나 | 클릭하면 간다, 누르면 뜬다, 한 일은 한 줄로 돌아온다 |
| 가시성 | 지금 상태·할 일·고를 것이 한눈에 보이나 | 상태는 늘 한 자리에, 할 일은 화면에, 고를 것은 버튼으로 |
| 개연성 | 이 규칙이 세계에서 나오나 | 이유 없는 규칙(균형용)은 없다. 있으면 사람 입으로 설명 |
| 자연스러움 | 보통 이 장르 게임이 하는 대로인가 | 타이틀 → 새로 시작 → 튜토리얼 → 하루 루프 → 결말. 대화창·메뉴·저장은 관습대로 |

## 쌓인 규칙 판정
| 규칙 | 잣대 위반 | 판정 |
|---|---|---|
| 짝수 날만 원정 | 개연성 — 왜 홀수 날은 못 가나 | **뺀다.** 날마다 갈 수 있고, 피로(원정 뒤 하루 쉼)가 자연스럽게 하루 걸러 만든다 |
| 세 사람만 배치 | 가시성 — 나머지 셋은 왜 못 움직이나 | **기본값으로 바꾼다.** 여섯 전부 세울 수 있되 셋은 자리가 미리 정해져 있다(바꾸면 값이 든다). 보통 게임의 '기본 배치' |
| 당신은 안 다친다 | 개연성 | **세계 규칙으로 설명한다**("것들은 당신을 세지 않는다", 세는 아이의 "…넷?"). 보통 게임의 '주인공 사망 = 게임 오버' 대신 '동행 사망'으로 |
| 땔감으로 역을 뜯는다 | 개연성 통과(불에는 연료가 든다) / 가시성 — 뜯은 자리가 보여야 | **둔다.** 뜯은 자리는 지도에서 빈다 |
| 수첩 이월 | 자연스러움 — 둘째 판에서 "버그?" | **둔다, D7에 드러낸다** |
| 카드는 아침에만, 저녁엔 한 사람만 | 자연스러움 통과 (하루 루프의 관습) | 둔다 |
| 결말 점수 숨김 | 가시성 — 왜 이 결말인지 | **점수는 숨기되 이유는 보인다**(명부에 탄 사람·약속·소원이 그대로) |
| 하루 원정 한 번 | 개연성 통과(낮은 하루에 하나) | 둔다 |
| 검표 두 번(빌드) | 자연스러움 | **고침**(징조는 꿈, 정원은 D9만) |
| D10에 하루를 또 삶(빌드) | 자연스러움 | **고침**(정오에 바로 열차) |

## 빌드 즉시 수정 (QA '출시 전 반드시' 1~9)
검표 중복 / 경상→위독 연쇄 / 추천 배치(경상자 휴식·발전기 기본) / 원정 보급 기본 4·4 / 승차 주민 먼저 / D10 바로 열차 / 글 4곳 / 순찰대 3번 값 / "통로가 있어야 열차가 선다"를 D1부터.

## PC 화면에서 지킬 관습 (GDD §2에 더함)
- 클릭한 칸까지 걷기, 마우스 올리면 설명, 오른쪽 클릭·Esc = 닫기.
- 상태(날짜·자원 셋)는 늘 오른쪽 위 한 자리. 사람 머리 위에 지금 하는 일 아이콘.
- 대화창은 아래 고정, 선택지는 번호 + 클릭. 긴 글은 ▼로 넘기되 **공백 누르기 한 번 = 한 문장**.
- 저장은 자동 + 슬롯 3 + 코드 내보내기. 불러오기 실패는 말로 알린다.
- 튜토리얼은 D1 하루가 맡는다(순례가 말해 준다). 따로 도움말 창은 두되 강제하지 않는다.
- 지도는 걷는 동안 무언가 보인다(사람의 움직임·물·안개·핏자국).
