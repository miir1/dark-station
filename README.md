# 어두운 역

A Dark Room식 대피소 키우기와 서울 2033식 선택형 원정을 섞은 한국어 텍스트 생존 게임. 설치 없이 브라우저에서 실행됩니다.

## 실행
- **앱으로**: 바탕화면 `어두운 역` 바로가기 (= `play.bat`: 8512 서버를 켜고 Chrome 앱 창으로 엶). 앱 설치(PWA) 지원 — manifest.json·sw.js가 게임 파일을 보관해 서버 없이도 열림. 파일 수정 후엔 sw.js의 CACHE 버전을 올릴 것.
- Claude 데스크톱 미리보기: `dark-station` (http://localhost:8512)
- 또는 `python -m http.server 8512 --directory C:\dev\dark_station`, 아니면 index.html을 바로 열기
- 진행은 브라우저 localStorage에 자동 저장(5초마다). 다른 탭으로 가면 시간 정지.

## 흐름
1. **어두운 역사** — 불 붙이기 → 땔감 넣기·선로 뒤지기. 따뜻해지면 정비공 한 씨가 와서 건설 개방.
2. **역 키우기** — 쥐덫·침상·손수레·버섯 재배실·정수기·작업대. 생존자가 모이면 직업 배치(10초마다 생산, 식량은 3명당 1 소비).
3. **지상 원정** — 출구 바리케이드를 지으면 개방. 식량·물·약품을 배낭에 챙겨 지역을 고름. 구역마다 식량 1·물 1 소모, 안개 지역은 방독면 없으면 체력 -1.
4. **선택형 사건** — 기술(관찰·완력·기술·말솜씨) 판정은 성공률을 공개. 도구·이전 선택(깃발)·배낭 물자로 선택지 개방. 체력 0이면 짐을 잃고 역에서 깨어남, 정신력 0이면 수집품 절반 잃고 도망.
5. **이야기** — 을지로 지하상가 → 종로 → 명동 → 용산 → (무전 설비) → 남산 송신소. 결말 4종.

## 파일
- `data.js` 자원·건물·도구·직업·지역·사건·결말 (내용 추가는 여기)
- `engine.js` 규칙(화면과 분리)
- `ui.js`, `index.html`, `style.css` 화면
- `test.js` — `node --test test.js`

지명은 실제 서울, 인물·사건 문장은 자체 작성.
