## 1. 줄타기 — 카르마 판에서 위험 0 출구를 없앤다
### 1-1 규칙
1. 구간은 **사건이 걸린 순간의 karma**: K0 0~4(지금 그대로) · K1 5~7 · K2 8~11 · K3 12~15 · K4 16+.
2. 대상은 §1-3 표의 선택지 30개뿐: ① 늦은 값 사건 5개(dawn_strike·dawn_mob·called_up·d10_hold·d10_grab)의 **모든 출구** 23개(싸운다 8 포함) ② 이른 위기·열병·D10·굶는 밤의 **남을 내밀거나 훔치는 출구** 7개.
3. K1 이상이면 위험 0 출구가 **판정**이 된다. 성공 = 지금 결과 그대로(비용도 그대로 먼저 낸다), 실패 = 당신 죽음 + §1-3 실패 글. 원래 판정이던 출구('싸운다')는 구간마다 base 를 깎는다.
4. 경고 = 지금 경고 + 종류별 꼬리(아래 표). 꼬리에 '끝이다'가 꼭 든다 — 화면을 읽는 사람과 봇(DEADLY 낱말)이 같은 뜻으로 읽는다. 화면에는 %와 ⚠만 보이고 카르마 숫자는 안 보인다.
5. 줄타기는 지금 swap 이 고른 모습 **위에** 얹는다(귀·손가락·다리를 잃는 변형은 그대로 + 판정). 원래 판정이 있으면 base = min(원래, 표).

### 1-4 강제 사망 0 증명 (03 '어느 선택지에도 살 확률이 있다' = 어느 사건에도 살 확률 > 0인 길이 늘 하나 이상)
1. 정의를 바꾼다: **확정 사망 = 고를 때 열린 선택지 전부 살 확률 0**. 살 확률 = 판정 없으면 결과가 당신을 죽이지 않을 때 1 · 판정이면 %×(성공이 안 죽임) + (1−%)×(실패가 안 죽임).
2. 바닥: 당신을 죽이는 판정은 base ≥ 30 (새 검사 R3) → 화면 % ≥ 30. 기술은 0 밑으로 안 내려간다.
3. 바뀌는 사건마다 비용·req·대상 없이 **늘 열린** 살 길 (가장 낮을 때 화면 %): dawn_strike 맞고 버틴다 70 · 밀쳐 낸다 35 / dawn_mob 맞고 버틴다 70 · 빈다 30 / called_up 손등을 깨물며 70 · 귀를 막는다 60 / d10_hold 끌려가며 70 · 뿌리치고 50 / d10_grab 끌려 넘어진다 70 · 발을 빼낸다 50 / d2 팔을 비틀어 뺀다 80 · d4 스패너를 막는다 80 · d5 퍼낸다 75 · 열병 불가에서 땀을 뺀다 70 · D10 이를 악물고 걷는다 70 (카르마 무관) / 굶는 밤 선로 밑(죽지 않음).
4. 나머지 사건은 바뀌지 않는다(지금 noExit 0건). 확정 죽음 선택 11개(대답한다·대신 대답한다 6 · 구두를 가지러 오른다 2 · 내주지 않는다 · 굶는 밤 눈을 감는다 · 운임 없이 탄다)는 남지만 다른 길이 늘 있어 '경고 있음·강제 아님'이다. 03의 괄호를 '모든 선택지에 살 확률'로 읽으면 이 11개를 판정으로 바꿔야 한다 — 디렉터 확인 1.
5. 시험: 20정책 18,400판 확정 사망 0. (지금 엔진 정의로는 '강제'가 정책마다 34~683판 — R1 없이 넣으면 안 된다)

### 1-5 swap 으로 되나 · 엔진에 더 필요한 것 (엔진 담당, 테스트 같이)
- **swap 만으로 된다** — 이 시험이 그렇게 돌았다: 선택지마다 [K4·K3·K2·K1] × (지금 swap 수 + 1) 줄을 앞에 붙인다(첫 맞는 줄). 다만 swap 이 20 → 225줄(+205), 성공 결과를 줄마다 복사해야 한다.
- **R0 [추천] 줄타기 열**: 선택지 열 `rope: { kind: pay|endure|point|fight, from: 5, blind: 0|1, fail: { text, how } }`. `effChoice` 가 swap 을 고른 **뒤** 구간을 보고 판정으로 바꾼다(성공 = 고른 모습의 out, 실패 = kill you + fail, warn += 꼬리 줄 `rope_tail_<kind>`). % 는 numbers 세계 수치(visible never) `rope_k1..4`(5·8·12·16) · `rope_pay_1..4` · `rope_endure_1..4` · `rope_point_1..4` · `rope_fight_1..4`(깎는 값 0·0·5·10) · `rope_floor`(30) · `rope_blind_pay/endure/point`(85·75·65). 표 한 곳에서 손잡이를 돌린다. 결과는 swap 판과 같다.
- **R1 강제 판정**: `choose()` 의 forced = 열린 선택지 전부 살 확률 0. warned·free 도 이 정의. `lastResult.alts[]` 에 `p`(살 확률). schema `noExit` = 살 확률 > 0 이고 비용·req·대상 없는 선택지 ≥ 1. karma.test 갱신.
- **R2 firstDeath**: 줄타기 판정(살 확률 > 0)은 1번 자리 '당신이 죽을 수 있다'에서 뺀다 — 줄타기 구간에서 1번 = 갚는다(가장 높은 %). 금기·확정 죽음은 그대로 경고. (swap 판이면 when 에 `karma>=`·`flag:strike_blind` 가 든 변형)
- **R3 바닥 검사 `ropeFloor`(오류)**: 당신을 죽이는 판정의 base(줄타기로 깎인 값 포함) < `rope_floor`. 지금 표 최저 35.
- **R4 집계**: `s.stats.ropeRolls`·`ropeClose`(줄타기 판정을 굴림·넘김) · `closeCalls`(모든 죽음 판정 넘김) · `lastResult.roped`.

### 2-3 측정에서 '누구나 아는 밤'과 실제 발견을 나눈다 (stats)
- `measure`: `privTotal`·`privFound` = public 1 또는 kill 효과가 있는 행을 **뺀** 주민 사건 수·그중 발견 · `pubTotal` = 누구나 아는 밤 수 · `blind`·`blindDeath`(봇이 dawn_strike 를 strike_blind 로 만난 횟수·그 죽음).
